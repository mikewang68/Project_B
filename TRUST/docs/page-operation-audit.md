# 页面操作留痕与设置接入

## 开发约定

有意义的用户动作通过 `useFeedback().act(meta, fn)` 执行。`meta` 仅含动作类型、固定菜单标识、可选资源 ID 和固定操作说明，不包含用户身份、组织、凭据、搜索词、文件名、表单正文或异常响应。服务端依据真实 IAM 会话确认主体与范围。

执行顺序为：持久化动作请求 → 验证 `RECORDED` 回执及相同请求 ID → 执行 `fn` → 报告客户端结果。请求留痕失败或回执无效时不执行 `fn`，界面保留原输入并提示重试。等待期间拒绝重复操作。

`fn` 必须返回完整的异步链，不能启动一个任务后立即返回，也不能吞掉错误；业务读取和修改放在 `fn` 内。不要在 `run()` 内嵌套 `act()`。返回成功仅表示浏览器观察到处理完成，不能据此断言数据库事务成功、原文归档成功或链上交易完成。服务端业务结果独立记录。

业务 HTTP 请求携带 `X-TRUST-Page-Action-Id`，服务端核实与当前主体一致后关联。该头不作为认证或权限依据。普通 HTTP 客户端统一添加关联；新增直接调用 `request`/`fetch` 的业务入口必须显式接入并验收。自动轮询在动作执行期间暂停，内部审计回执不携带关联头以避免循环。

客户端结果上报失败时显示“仅补报结果”。它只重发结果，不重做业务请求。待补报内容仅在当前页面内存中保存，退出或关闭页面后不会由另一个用户补报；请求记录仍留在服务端，结果可能未知。浏览器崩溃、进程被关闭或页面卸载不能保证最终结果送达，不使用不可靠的卸载回调宣称闭环。成功退出会话后不再发送需要鉴权的结果请求，退出结果由服务端记录。

## 当前操作覆盖清单

| 页面 | 受控动作 | 自动行为及明确边界 |
|---|---|---|
| 工作台 | 首次进入、菜单切换、打开详情、返回列表、开始更正、退出 | 首次进入未获回执不加载业务页面；受控恢复入口可退出会话 |
| 事件台账 | 查询、上下页 | 定时刷新不作为新用户动作；查询内容不入浏览器日志 |
| 录入与导入 | 提交事件、上传、导入、取消更正、移除附件引用 | 输入过程、逐键内容不采集；关联文件内容不进入页面动作记录 |
| 事件详情 | 核验、导出、下载证据、跳转历史 | 打开页面产生导航/读取记录，自动加载和轮询不另造页面动作 |
| 溯源 | 查询、打开事件 | 不采集搜索词 |
| 补办任务 | 刷新、显式补办、打开详情 | 轮询不触发补办 |
| 身份 | 手动刷新 | 页面激活读取不重复生成用户动作 |
| 托管钱包 | 刷新、申请、复核、开始绑定、链授权查询 | 钱包入口维护者必须使用相同 `act` 包装；见钱包页面实现与独立验收 |
| 运行状态 | 重新检查、刷新日志状态、保存日志设置 | 设置读取失败不能推断有修改权限 |
| 外观 | 更改主题、布局、恢复默认 | 打开/关闭本地面板、滚动和技术详情展开属于展示行为，不作业务操作审计 |
| 登录 | 服务端认证过程 | 未登录浏览器不能调用已鉴权页面留痕接口；失败、拒绝和登录结果由服务端覆盖 |

新增页面、功能按钮、键盘提交、文件输入和导航入口必须更新本表。验收至少验证留痕失败时业务请求未发送、同一动作的关联 ID、重复点击、失败结果、无敏感正文、断网后仅补报结果。业务状态与链回执必须另行验证。

## 日志设置

运行状态页面读取 `/api/v1/audit/settings`。操作采集始终开启；原文归档与上链处理可分别暂停和恢复，已接收原文与待办仍保存。展示积压、最早待办、失败数量及安全原因。写控件只在 `canManage` 为真时提供，服务端独立授权；`ROLE_ADMIN` 或审计读取权限不代表设置写权限。

修改提交完整暂停值及原因，由服务端记录设置变更。浏览器不显示服务凭据，不向其他模块下发全局开关。未配置、未知及不可读取状态不能显示为已完成。

## 其他模块接入

各模块在自己的前后端实现相同先留痕再执行的契约，浏览器只调用本模块后端，服务凭据留在后端。TRUST 代码不替其他模块改动 UI 或业务事务。必须分别验证客户端动作与服务端权威结果；仅通过 TRUST 模拟浏览器测试不代表其他模块已接入。

本地无界面验证：启动 TRUST 前端后运行 `node TRUST/tests/audit-ui.cjs`，可用 `TRUST_BASE_URL` 指定本地地址。测试拦截 API 为合成响应，仅验证界面门控、隐私、关联和设置行为，不证明 IAM、IPFS、数据库或 Fabric 正常。报告和截图写入 `.local`。
