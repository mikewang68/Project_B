# TRUST 新版前端及开发快捷登录发布 · 2026-09-22

本次修正此前“只发布导航、TRUST 仍运行旧 JAR”的遗漏。新版已发布到应用节点 `/data/app/trust`，网关 18080 返回本次构建的前端。此前目录迁移保留原制品，本次才是前端及快捷登录功能升级。

## 已发布功能

- 四套皮肤、三种工作台布局及外观偏好持久化。
- 管理员、录入员、查询员、外部查询员快捷登录，保留普通账号密码登录。
- 服务端 `GET /api/v1/dev-login` 只提供预设账号的名称、角色、组织；`POST` 接收账号名称，经服务端实际密码认证建立会话。密码不返回浏览器。
- 开发登录默认关闭。此内网实例通过 `runtime/secrets/dev-quick-login.enabled` 标记显式启用，启动脚本传入 `trust.dev-quick-login.enabled=true`。移除标记并重启即可关闭。该功能等同于向获准访问开发实例的人员开放预设开发角色，不能在公网或生产实例启用。
- POST 仍受 CSRF 保护，认证后更新会话 ID 和 CSRF，数据库角色和组织范围继续生效。

## 验收

- Maven 7 项测试中6项通过、1项独立数据库集成测试跳过；新增默认关闭、密码不泄露、账号白名单及会话更新测试通过。
- 真实浏览器四类快捷登录通过，审计权限及外部组织零记录隔离通过，无 CSRF 登录及非法账号被拒绝。
- 真实前端9项检查通过，包含换肤布局和移动端；普通登录及29条事件、29个完成任务、三个依赖健康通过。
- HTML、JS、CSS 与本地构建逐字节一致。公网导航访问 `/api/v1/dev-login` 返回404。
- `check-http-access.py` 增加本地 dist 与在线前端内容比对，避免再把“资源可访问”当作“新版已上线”。
