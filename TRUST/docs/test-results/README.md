# 公开验收摘要

本目录保存脱敏摘要；详细运行 JSON、截图和原始证据包由维护者在本机保存。测试程序默认写入 `.local/test-results`，不会自动更新公开结论。

## 历史验证 · 2026-09-10 至 2026-09-13

| 验证方式 | 结果 | 边界 |
|---|---|---|
| 原生 IPFS/Fabric 组件 | 文件保存、固定保存、取回；合约登记、幂等、冲突、身份、更正、历史与分叉拒绝通过 | 组件测试，不等同于应用端到端 |
| Java Gateway | TLS、双组织背书、有效提交和回读通过 | 在 Fabric 节点使用实际 SDK |
| 目录重构回归 | 4 个单元测试及 1 个真实 openGauss 多场景集成测试通过；12 项模拟接口页面检查通过 | 集成测试的外部服务使用故障注入 |
| 四节点应用 | 13 项真实接口与恢复检查通过 | 实际应用、openGauss、IPFS、Fabric；业务输入明确为模拟 |
| 实际页面 | 8 项无界面 Chrome 检查通过 | 登录、台账、在线核验、溯源、录入页面展示、任务、状态及移动宽度 |
| 离线工具 | 合成包的正常、缺失、替换、错误参考摘要检查通过 | 文件一致性验证，不构成独立链上证明 |
| 单组件恢复 | 独立 IPFS 恢复、开发测试数据库恢复及独立启停通过 | 同组协调备份恢复尚未验收 |

钢材样例为 100 吨，分 60 吨和 40 吨两次发运；十条事件均完成实际归档与上链，两次发运能追溯到同一来源。两份实际导出包逐文件核验，并与另一次在线链查询返回的清单摘要比对通过。

真实应用验证了并发重复提交、同号异文、迟到补齐、追加更正、越权请求、IPFS 停机后自动补办、Fabric 停机时文件先保存、普通应用重启续办、人工重排复用原交易、项目连接中断与恢复，以及数据库断连时返回 503 后由来源补传。结束时开发环境共有 19 条事件与 19 个完成任务。

单次开发基线：744 字节 PDF 上传 1.141 秒、事件接收 1.156 秒、从开始提交到观察到上链完成 3.656 秒；六种溯源查询合计 6.359 秒。包含 SSH、HTTP 与轮询开销，不是生产性能指标。故障测试总耗时不作为 RTO。

## 复现入口

先按模块 README 配置环境。配置检查使用 `tests/test_deployment.py`；组件测试使用 `tests/component-real.py`，其输出可供 `tests/recovery-components.py` 使用；应用使用 `tests/cross-node-real.py`；前端目录执行 `pnpm test:e2e`。所有故障演练仅在专门的开发实例执行。
