# EHMS 公共已提交事件业务消费适配

负责人：闫鑫钰。版本：EHMS-PUBLIC-DATA-1.0.0，2026-11-12。

本包是**新增消费适配的源码与可运行独立 worker 交付**，不是完整 EHMS 系统覆盖包。与董博涵原交接包配套使用；不含任何 HTTP/MQ/数据库/工作台口令。验收事实以 `reports/测试与联调结果.json` 和回执为准，不把本地测试写成生产验收。

## 做了什么

1. 对正式 `b-device-committed-v1` 提供 RocketMQ 消费适配，独立组 `b-device-committed-ehms-v1`；HTTP 按设备历史补读，与 MQ 共用同一数据库接收箱和业务去重。
2. 可靠落箱后才允许 MQ ACK。业务处理另外在同一个 openGauss 事务中完成：业务聚合变更 + 接收箱 APPLIED；失败全部回滚，原消息持久保留、60 秒后重试，最多 10 次，修复后可显式补偿。
3. 对已分配的设备/测点建独立 `MQ-SIM-…` 业务编码，写入现有 EHMS `aggregate_store` 的设备、采集分组、测点、质量快照、设备快照和独立时序；原有 SAMPLE-LIVE 模拟设备、定时器与业务数据不替换、不迁移。
4. 保留完整原事件、原字节 Base64、wire_sha256、单位、质量、空值、来源时标、资产引用。按配置指定的 PROJECT_B / EHMS_DEMO / EHMS 入库，消息字段不能指定数据库作用域。
5. BAD/STALE 产生“采集质量异常”提示告警；持续同一异常不按每条样本重复发警。它不是设备物理故障诊断，不自动创建/批准检修工单，也不自动关闭人工处置中的告警。
6. EHMS 时序查询补丁把 MQ-SIM 测点路由到受中央区域权限约束的业务库历史查询；普通测点、原 openGemini、SAMPLE-LIVE 路径保持原状。

## 明确不冒充的能力

- 公共目录只有 4 台相关模拟设备。需求点 572 行；当前目录相交 413 点，其中 3 点缺少映射。不是 572 点全部已经通。
- 原点表含厂家、单位、极性、限位、急停等待确认项。本包不下发 PLC 控制，不猜 0/1 安全含义，不把原始健康字段当作 EHMS 结论。
- 标量、字符串/枚举、数组/波形引用分别处理；不生成假 FFT、假寿命预测。缺源时标不以接收时标伪装；质量未知/坏/空值不当正常值或零。
- 未配规则的公共测点不使用旧逻辑“默认 50% 利用率”生成健康分。经工程师配置正值上限且质量合格后，才可由原 EHMS 规则评估流程使用；不是厂家认证或 AI 预测。
- wire_sha256 是入口 wire 字节的摘要，本包保留并比对公共回执；不能拿重序列化 JSON 假装验证 wire 原字节。本包另算接收字节摘要供隔离记录去重。
- 不发布任何共享业务结果 topic，不使用只读身份冒充 producer；未修改日志/链上存证接口。

## 可选前端开关的选择

董博涵说明前端开关自愿。本次优先交付必须完成的“公共消费到业务库”，**未修改公共 Vue 工作台或增加其按钮**，因此无需要董博涵合并的共享前端文件，也没有页面挂载自动开生成器的行为。

开发联调采用显式、有时长和条数上限的 CLI；配置默认 disabled，不安装常驻任务、不自动消费正式组、不控制公共设备生成器。现有 EHMS 后台“动起来”的模拟任务继续保留。若日后要把 CLI 包为工作台按钮，必须由工作台服务端授权、审计并代理，禁止把数据库或 MQ 凭据下发浏览器。

## 包目录

- `worker/`：独立 Maven 工程、worker 源码、必要领域模型和 23 项数据库事务测试。
- `bin/`：与源码对应的 Java17 worker JAR、隔离 MQ transport JAR；`lib/` 为 worker 必需依赖。
- `mq/CommittedMqMain.java`：RocketMQ transport 源码，使用原交接包里的 5.3.3 client JAR；不向生产 EHMS web classpath 添加其旧依赖。
- `ehms-web-patch/`：EHMS 两处网页后端适配的最小 diff、对应源码与测试。**不能用这些文件覆盖整套系统。**
- `mapping/`：从原交接包按 EHMS 需求筛选的目录/点表、覆盖统计和待确认项，不含凭据。
- `config/worker.config.example.json`：默认关闭的无密钥模板。
- `docs/`：运行、SQL 查询、恢复、业务接口和验收说明。
- `reports/`：实际执行的测试摘要与现场联调状态。
- `MANIFEST.json`：交付文件摘要；原 ZIP 的摘要另记在回执。

先看 `00-给董博涵的回执.md`，运行操作见 `docs/部署与验收.md`。任何生产库部署都必须先核实实际连接、区域和 IAM 登记，不要把测试 H2 当成服务器 openGauss 验收。
