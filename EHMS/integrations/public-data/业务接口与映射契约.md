# EHMS 消费与业务映射契约 v1

## 输入

|入口|输入|接收成功含义|
|---|---|---|
|MQ|`b-device-committed-v1`，`b.device-committed.v1` envelope，key 为 event_id|消息持久进入 EHMS inbox 或隔离箱；不等于 APPLIED|
|HTTP 历史|`/api/device-data/v1/history` 每设备 limit≤100，opaque cursor|逐条验证 `/events` 的 COMMITTED、event_id、wire_sha256、broker_message_id、device_id 后，在同库事务中落箱+保存该条 cursor|
|HTTP 回执|事件在 receipt.event，`b.device-event.v1`|同一 event_id 不同正文或 wire_sha256 隔离；不静默覆盖|

必需事件字段：`event_id`, `device_id`, `schema_version`, `simulated=true`, `observed_ts_ms`, `payload.points[]`。源时标 `source_ts_ms` 可空；测点可带自己的 `source_ts_ms`，存在时优先，显式 null 不回退成伪造源时间。point 使用 `point_code,value,unit,quality`，保留全部其他字段及资产引用。

时间为非负整数 epoch 毫秒；缺观察时标、重复点号、非法结构为业务 FAILED。未知设备保存但业务 IGNORED。没有单位转换授权时严格按原单位，单位与目录不一致的值保留但不参与健康计算。未知质量保留原值；非文本质量在原文完整保留，不能当 GOOD。

## 持久结构

|类型|作用|
|---|---|
|`ehms_pd_consumer`|sourceId 与目录、身份、策略、目标作用域不可变绑定；并发事务行锁|
|`ehms_pd_inbox`|源事件去重、wire 摘要、原事件 JSON、接收字节 Base64、transport、状态、尝试次数、下一次重试|
|`ehms_pd_cursor`|按入口/身份/策略/设备/目录区分的 opaque cursor；不能跨过滤条件沿用|
|`ehms_pd_quarantine`|消息冲突/非法信封原字节 Base64、原因与摘要；与 inbox 原记录分开，不覆盖|
|`aggregate_store` 的 `asset/component/measurement-point`|沿用 EHMS 原领域对象和作用域；新建独立公共模拟设备与采集分组，绝不按名称合并原设备|
|`committed-observation`|每事件每点的无损业务观察，含 rawPoint/来源时标/单位/目录映射状态|
|`committed-latest`|每设备点的最新原始观察，迟到数据不能回退 latest|
|`committed-telemetry`|仅确定的标量点，保留质量和源时标，未知/坏值不会被替换成零|
|`point-quality/device-snapshot`|沿用 EHMS 数据质量/设备展示对象；坏值在评估视图中不可用，health/RUL 默认空|
|`committed-business-receipt`|event_id、设备、映射/待确认数量、模拟标记和未发布状态；与 APPLIED 同事务|
|`alarm`|只对显式 BAD/STALE 发采集质量提示，不解释安全位、不作物理故障诊断|

所有聚合都写到私有配置指定的 `(projectId,regionId,'EHMS')`。输入不能修改这三列。历史 audit/链上 payload 不改。对外查询仍由原中央 IAM + 业务权限过滤器验证。

## 状态与回执

`PENDING → APPLIED / IGNORED`；可恢复错误 `→ FAILED`，间隔60秒、10次后等人工补偿。

`QUARANTINED` 是接收接口返回的隔离结果，原文在隔离箱，不能计为业务 APPLIED。MQ 可在可靠隔离后确认消息以免毒消息阻塞；HTTP 保持冲突事件之前的进度。数据库接收事务失败不得 ACK。

同一个输入若 HTTP/MQ 重复传入，仅接收箱 NEW 一次，业务效果只生效一次。业务事务和 APPLIED 同库同连接提交；异常回滚所有半成品。更换身份/目录/作用域必须重新规划消费器，不能修改原检查点绑定。

## EHMS 现有查询 API 的适配

`GET /api/ehm/v1/telemetry/points/{pointCode}/samples?from=<ISO-UTC>&to=<ISO-UTC>&limit=500`

- 对 `MQ-SIM-` 点查询受当前 IAM 区域过滤的 `committed-telemetry`；默认最近24小时、上限10000条，按源时标排序。
- 对其他点继续原 TelemetrySeriesPort；公共库失败不降级到假数据或其他区数据。
- 原样返回 TelemetrySample 的 pointCode/assetCode/metric/unit/value/quality/sourceTimestamp/receivedAt。复杂值、波形引用不塞进 Double 字段，保存在观察聚合。
- 本次不新增免认证公开 API，不新增 IAM 权限码，不以管理员身份兜底。没有区域授权仍 403。
