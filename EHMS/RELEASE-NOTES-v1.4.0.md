# EHM v1.4.0 服务器版发布说明

本版本继续使用 `openGauss + openGemini` 服务器主线，不新增MongoDB服务器依赖。

## 新增可用功能

- 我的待办：新增、编辑、责任人/班组、优先级、截止时间、处理中和完成闭环。
- 班组交接：手工草稿、从活动告警与未闭环工单自动汇总、交班提交、接班确认。
- 设备模板：标准部件、测点、采样参数、点检策略、草稿编辑和审批发布锁定。
- 计量校准：设备/部件/测点/传感器关联，校准前后值、允许误差、结论、证书及有效期。
- 配置变更履历：变更前后JSON快照、原因、影响评估、申请、审批和生效记录。

## 业务控制

- 已完成待办不可重新编辑。
- 交接必须按“草稿 → 已提交 → 已接班”顺序流转。
- 已发布设备模板不可原地覆盖。
- 校准记录采用追加式历史，不覆盖原记录。
- 配置变更必须先审批再确认生效，系统只记录治理流程，不直接下发PLC参数。

## 数据与接口

- 五类新业务聚合通过Repository端口接入openGauss聚合存储。
- OpenAPI契约升级至1.9.0。
- 增加五类领域状态机测试，完整测试集在Java 17环境通过。
