# EHM 1.3.0 服务器联调版

## 本次完成

- 服务器交付包正式包含 `preference.js` 与 `unified-theme.css`，支持4套皮肤和3种布局。
- 打包阶段增加前端关键文件完整性校验，缺少换肤资源时直接终止打包。
- MongoDB演示方案退出服务器交付与后续开发基线；业务数据使用openGauss，时序数据使用openGemini。
- 实时告警中心增加受控批量分派，分派结果由后端状态机校验并持久化到openGauss。
- 增加批量分派领域测试，继续保留操作审计与追踪号。
- 修复openGauss JDBC对`Instant`更新时间的类型推断错误，改为显式`Timestamp`写入。
- 运行能力接口改为根据当前持久化与时序适配器动态报告，不再错误显示MongoDB为服务器主库。
- 服务器基线已通过60项自动化测试及openGauss/openGemini端到端CRUD冒烟测试。

## 当前边界

- 统一IAM、现场PLC/网关、RocketMQ事件总线、区块链存证和正式AI推理仍需外部接口与环境参数。
- 页面中明确标注为“待接入”或“条件待定”的能力，不计入已实现验收范围。
