## 1. 设计依据与边界

以《设备健康管理系统需求文档-v1.3-20260721》为基础，以湖北远程提供的《B项目智能装卸管控系统__20261030.pptx》作业务补充，不用新PPT替代原需求。重点对应PPT第31—33页的设备台账、设备资料、维护提醒、故障辅助分析，以及第9—13页的系统职责边界。

PPT中的原型数量、曲线、剩余寿命和维护周期不直接转换为现场参数；厂家资料未知时明确显示待提供。设备健康系统不下发PLC控制、不复位设备、不替代急停和安全联锁，AI建议不自动转成维修执行指令。

原有菜单、可视化、统一换肤、IAM登录、后台模拟数据调度、审计链路和AI模型切换代码保留。未修改账号、密码、IAM授权或模型密钥。本轮测试不代表上述外部服务已经重新完成真实端到端验收。

## 3. 数据及接口

档案元数据使用现有openGauss聚合存储，新增类型 `asset-dossier`，保留原资产结构；本轮不增加Mongo依赖、不更改openGemini路径。资料实体经独立存储端口保存，后续可替换为公共文件服务。

根路径：`/api/ehm/v1/devices/{code}/dossier`。

| 方法与后缀 | 用途 | 权限边界 |
| --- | --- | --- |
| GET 根路径 | 读取设备档案 | 当前范围可见设备及档案VIEW |
| PUT 根路径 | 保存基础信息及维护依据，携带version | fleet EDIT及原生archive:edit；只读身份拒绝 |
| GET /maintenance-due | 按已登记依据计算状态 | 同档案读取 |
| POST /documents | multipart上传资料，含version/title/kind/revision/file | fleet EDIT及原生archive:edit |
| GET /documents/{id}/content | 校验完整性后附件下载 | 同档案读取；已归档或其他设备资料不可读 |
| DELETE /documents/{id}?version=… | 软归档资料，保留文件和历史 | fleet DELETE及原生archive:edit |

相关原生读权限为 `ehealth:asset:archive:view`，写权限为 `ehealth:asset:archive:edit`。中央动作与原生权限共同约束，不以本地管理员角色覆盖缺失的IAM动作授权。

所有接口继续经过既有请求审计过滤器；本轮没有执行真实AUDIT/TRUST链上回执联调，因此不据此声称新接口已获链上确认。

返回约定：缺字段/非法文件400；权限不足401/403；不可见或已归档资料404；版本冲突409；multipart超限413。表单失败不自动关闭，不展示“保存成功”。

## 4. 界面与业务验收

### 本地界面预览

地址：`http://127.0.0.1:18394/?page=asset-profile`。

这是明确标识的纯界面虚拟样例：只在内存保存，不连接真实数据库、IAM、模型或PLC，也不使用服务器账号。用于检查布局、分区、编辑反馈、必填项、焦点和菜单搜索；不能用它验收上传入库、真实登录或上链。

预览脚本：`tests/serve_ui_fixture.py`。服务停止后，可使用本机Python运行：

```powershell
python tests/serve_ui_fixture.py --web ./web --port 18394
```

请在本工程目录执行；若 `python` 不在PATH，使用本机Python的完整路径。

### 真实服务后续验收顺序

1. 使用现有服务器IAM账号登录，不新增或重置账号；检查原菜单、图表、AI与后台模拟任务仍可用。
2. 用有fleet EDIT/DELETE动作的身份进入设备档案，保存后刷新核对；普通只读身份不能写入。
3. 上传虚拟TXT资料，下载比对内容；同名同版本拒绝；归档后不再下载；正在作维护依据的资料禁止归档。
4. 关联虚拟资料，登记HOURS周期100、提前10、上次0、当前95，应为即将到期；当前105应为到期。该数值仅作接口验收，不是设备寿命。
5. 两个会话同时编辑，旧version提交应返回409，不覆盖新数据；跨项目/区域不得看到其他范围资料。
6. 生成维护任务时原计划到期日不变；合格完成后顺延。复测失败不允许关闭；再次维修后须复测。
7. 检查日志记录及公共AUDIT投递，链上状态以TRUST真实回执为准，不以本地保存成功代替。

## 6. 发布与运维注意

本轮仅修改本地源码，未生成可直接覆盖线上全站的部署包。服务器已有IAM和公共前端定制，后续应逐文件合并本批改动并带回滚验收，不能拿本地整套旧页面替换线上。

正式启用资料上传前，配置 `ehm.documents.root`（环境变量可用 `EHM_DOCUMENTS_ROOT`）为服务账号独占、可写的固定持久目录。不能放入静态站点、可公开的release目录或临时目录。Linux目录700、文件600；文件与数据库元数据必须一起备份。路径不能通过符号链接重定向；由有权限的管理员预建并确认所有者。不要为此开放公共目录访问私有文件。

文件与数据库不是分布式事务；极端情况下资料文件已写入而元数据CAS失败会留下不可经业务接口访问的孤立文件。暂不自动删除，后续增加经核对的孤立文件清理工具和存储配额告警。

后续服务器候选包必须以server配置构建，不使用本地模拟运行专用profile打包；不包含私钥、密钥、真实附件、账号配置或测试数据库。
