# EHM服务器版功能实现状态（v1.4.0）

本文只统计 `openGauss + openGemini` 服务器主线。

## 本次新增完成

- 我的待办：具备新建、编辑、责任分派、优先级、截止时间、状态和完成闭环，刷新后数据仍保留。
- 班组交接：可手工创建，也可从活动告警与未闭环工单自动汇总草稿；支持交班提交和接班确认。
- 设备模板：独立保存标准BOM、测点、采样参数和点检策略；草稿可编辑，发布后锁定。
- 校准记录：保存传感器、测点、校准前后值、误差、结论、证书和有效期，并统计临期/受限记录。
- 配置变更履历：保存变更前后快照、原因、影响、回滚基线、申请/审批/执行信息。
- 五个菜单已改为独立业务页面，按钮调用真实后端API，不再复用通用占位页面。

## 数据保护规则

- 校准与配置变更采用追加历史，不直接覆盖已有凭证。
- 配置变更遵循“草稿—审批—生效”，仅记录流程，不直接向PLC写入控制参数。
- 自动交接只生成草稿，必须由交接双方签认。
- 演示初始化仅在对应聚合为空时写入，不覆盖服务器已有数据。

- 统一IAM/JWT、生产TLS、备份恢复与灾备。
- RocketMQ事件总线和区块链存证接口。
- 正式AI模型、训练数据和推理硬件。
