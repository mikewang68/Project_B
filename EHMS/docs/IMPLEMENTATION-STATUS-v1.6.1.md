# EHM 1.6.1 实现状态与边界

| 能力 | 当前状态 |
|---|---|
| 服务器业务/时序存储 | openGauss事务数据、openGemini测点历史；server profile禁用Mongo自动配置 |
| 统一主题和布局 | 已实现，保留统一设置同步与本地选择 |
| 业务管理 | 台账/BOM/测点、告警、工单、待办、交接、模板、校准、配置履历等通过后端接口持久化 |
| 维修及备件闭环 | 点检、缺陷、工单、复测、库存、预留、领用、采购建议及业务校验已实现 |
| 可视化 | 统计接口计算业务分布与时间线；测点历史及评估历史驱动趋势，显示数据来源与时间 |
| 无数据/失败反馈 | 显示空状态、加载错误与历史回放提示；不使用固定图冒充真实数据库结果 |
| AI接入 | OpenAI兼容供应方适配、模型/来源显示、隐藏Key配置与精确受信任HTTP origin |
| 模型查询 | 默认由服务端先检索并脱敏；网关兼容验证后可启用只读工具调用 |
| AI写入边界 | AI生成草稿，用户确认后才经业务接口执行；不直接写数据库或控制设备 |
| 预测边界 | 已实现规则评分、趋势与人工审核；无适配预测模型不编造寿命或置信度 |
| 未完成的生产集成 | 统一IAM、正式事件总线、现场协议接入、灾备及容量压测仍待实施与验收 |

源码测试不等于现场业务验收或诊断准确率验证。模型输出可能混淆设备编号，必须核对数据来源和业务草稿。
批准的脱敏数据策略是本版外部模型调用前提；不可把自动脱敏视为涉密内容外发授权。
所有真实连接参数与密钥在部署环境保留，不发布到公开仓库。
