# 1.8.1-server：可持久化虚拟场景与功能验收

新增受控虚拟场景包：8台设备、8个部件、24个测点、1176条虚拟时序样本、78条虚拟历史评估、8条告警、8张工单、8份闭环档案、8份维护计划与点检任务、8份校准/配置变更/待办、3份交接、3种模板/失效模式/规则/知识案例/备件及库存、5级SLA。后续验收会新增自己的测试记录，不应把页面总数当作真实现场规模。

全部样例用SAMPLE-或[虚拟]明确标注，固定数据包版本和首导入时间；重复导入只补缺失条目，不覆盖编辑、归档、审核、密码或历史。没有清空、重置、自动导入或任意JSON/SQL上传入口。import/tick均需超级管理员和CSRF，并进入现有业务审计。此功能默认关闭，不能把功能开关当作通用生产数据导入工具。

隔离演示配置：`EHM_SAMPLE_DATA_ENABLED=true`；若没有时序服务器，可显式选`EHM_TELEMETRY_ADAPTER=sample`。该适配器使用当前业务库的独立sample-telemetry聚合保存虚拟样本，只接受SAMPLE-设备/测点，不能接收真实点位，也不是openGemini失败后的自动降级。正常服务器默认仍为openGauss/openGemini，Mongo没有重新启用。

新增“集成与系统 → 演示数据与功能验收”页面，列明各菜单为业务接口已实现、部分实现或设计展示。图表仍查询后端持久化数据；样例不代表经训练寿命模型、现场采集或真实链上记录。手动虚拟采样只更新样例快照与样本库，不自动刷新时间掩盖断流；长时间不采样会正常过期。RUL保持未启用。

设备360详情新增当前设备关联BOM、测点、校准、配置变更、工单履历和已保存健康评估曲线，缺少额定参数、图纸、证书附件时如实提示。没有凭空生成真实厂家资料或部件健康分。服务能力页修正两类角色已实装但仍显示“仅设计预览”的过时说明。

新增样例安装/重复导入/数据保留/虚拟时序边界集成测试、4项前端回归和显式本机HTTP业务验收脚本`EHMS/scripts/verify-sample-workflows.py`。测试记录不等于实际openGauss、openGemini、统一IAM、外部大模型或Fabric联调结果。
