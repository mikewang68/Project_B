# 1.7.4-server：可查询的持久化日志

- 兼容 IAM `/auth/me` 的数值成功码 0/200；缺失、字符串或溢出码拒绝，身份仍须后端在线验证。
- TraceId 在日志、来源与身份过滤器之前建立，早期401/403保留统一追踪号。
- 在可信 `/auth/me` 的 `data.readOnly` / `data.user.readOnly` 布尔标记，或 `data.roles` 字符串/对象code列表命中受支持只读角色时，后端优先拒绝写操作、敏感导出与重试。浏览器同名字段不授予权限。其他字段位置须在真实IAM联调后适配；不是全业务RBAC验收。
- 新增本模块数据库日志分页、精确条件筛选、详情、公共服务回执在线查询。默认仅本人事件；`EHM_AUDIT_QUERY_ACTORS` 为本地专项读取名单，且仍固定当前应用/Domain/Zone，不是中央跨域授权。
- 匿名不再取得旧接口的日志身份明细。原日志不可改、不可删；不提供清库绕过冲突功能。
- 回执在服务端核对eventId/appCode/payloadHash/stored；缺凭据、查不到、失联、校验失败均不认定链上完成。
- `audit-browser.js` 新页面直接查询后端，支持翻页、详情与手动回执刷新。会话验证仅验证已有IAM令牌，不是新登录系统，也不实现全局注销。

继续使用openGauss/openGemini。本版本不增加业务表迁移，升级1.7.3之前的实例仍需先执行002/003。生产运行关闭自动DDL，私有配置与旧版本分别保留。真实TRUST来源与正文归档未经确认时，上链保持关闭。
