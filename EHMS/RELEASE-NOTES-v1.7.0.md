# EHM 1.7.0 公共日志接入

- 查询与写接口均记录本地审计；可信用户取自Servlet认证身份，不再采信浏览器操作者请求头。
- server模式新增openGauss持久化audit_outbox；核心业务HTTP命令与日志入队在同事务提交，失败回滚。查询、拒绝及失败请求独立记录。
- 定时投递WriteLog公共服务，核对事件编号、内容摘要及可靠入库回执，网络故障保留任务并重试。
- 前端补充菜单浏览与客户端导出意图，标记CLIENT/STARTED，不宣称业务已完成。
- 审计页面增加队列与公共API配置状态；链上结果在公共日志控制台查看。

升级前执行sql/002_audit_outbox.sql；先构建AUDIT SDK再构建EHM。域、区域、端点及凭据文件在私有环境配置，不改数据库为MongoDB。

独立服务地址、可信IAM登录及区块链日志合约需完成真实联调后验收。源码提供的是可执行接入能力，不能据此宣称六个模块全部接通或真实Fabric已上链。助手等外部调用以请求层审计，不承诺与外部平台操作事务原子性。
