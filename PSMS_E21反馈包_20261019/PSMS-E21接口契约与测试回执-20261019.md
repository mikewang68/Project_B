## 4 首个只读接口契约

### API-012 运行态势快照

| 项目 | 内容 |
|---|---|
| 方法和路径 | `GET /api/monitor/operations` |
| 查询参数 | `workArea` 可选；正式接入需明确允许的区域值和数据域过滤规则 |
| 当前实现 | Express 路由读取工单、设备和最近遥测，返回 `workOrders`、`equipments`、`telemetry` |
| 业务库 | openGauss，当前默认配置为 `psms` |
| 时序库 | openGemini，当前默认配置为 `psms_telemetry` |
| 当前认证 | 路由使用 `optionalAuth`；正式统一 IAM 接入前不能作为最终权限验收 |
| 当前 operationId | `GET_mock_operations`，名称仍保留 mock 字样；正式契约建议改名或明确兼容关系 |
| 写入影响 | 接口本身为 GET；本轮未执行真实服务器请求，不声称已通过 HTTP 200 验证 |

可继续核对的只读路由包括：`GET /api/plans`、`GET /api/work-orders`、`GET /api/appointments`、`GET /api/exceptions`、`GET /api/interlocks`、`GET /api/offline/packets`、`GET /api/reports`、`GET /api/settings`、`GET /api/audit-logs`。这些路由的 E21 隔离服务器地址、真实数据样本和 HTTP 结果待负责人提供。
