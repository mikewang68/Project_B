# 场站精模参考资料记录

本期 GLB 资产由 Blender 中的原创参数化几何制作，不内嵌网络图片、商标、厂商标识或第三方整机纹理。

- CAD 几何依据：`train.dwg` / `assets/cad/train.dxf`。
- 设备形态依据：轨道式门式起重机、粉料筒仓、敞车的通用工业结构；仅用于比例、构造和材质判断。
- 落位依据：`apps/admin/src/twin3d/placements.ts`。所有位置均标记为 `inferred`，等待设备尺寸表、现场照片或测绘资料复核。

后续若引入外部 HDRI、材质或模型，必须在本目录补充来源、许可证、下载日期和用途；不得在运行时从公网下载。
