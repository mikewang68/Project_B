# 钢材卸车与堆存答辩演示脚本

## 演示准备

1. 打开数字孪生首页，确认左侧“答辩演示 · 钢材卸车”处于初始状态。
2. 确认“状态模拟”为关、“龙门吊动画”为关；钢筋露天仓位汇总为 12,500t / 16,000t，钢材卸车任务为 0%，暂无告警。
3. 建议先点击“核心总览”，向评审说明：低亮度 CAD 线框只作工程核验底图；GLB 模型、铁路平车和业务状态均使用统一 CAD 本地坐标落位；规划转运区以“规划中”单独呈现。

## 五阶段讲解

### 1. 钢材平板车入场

点击“开始演示”。铁路平车沿钢材两轨驶入 CR-02 作业区；此时 CR-01、CR-03 保持待机，任务进度开始推进。

### 2. 龙门吊定位

系统自动切至龙门吊近景。说明吊车门架保持静态，浏览器只驱动小车横移与吊具升降，因此将来可以用真实调度或传感器数据替换当前演示时间线。

### 3. 起吊卸车

吊具起升、横移，钢材卸车任务继续推进。强调设备状态只控制状态灯和业务信息，不改变设备主体材质，保证工业夜景下的模型可读性。

### 4. 钢材堆场入库

系统切换至钢筋露天仓位视角。钢筋仓位汇总库存由 12,500t 增长至 13,200t，钢材卸车任务达到 100%。这一步说明三维作业、库存数据和任务进度来自同一演示步骤。

### 5. 堆位预警核验

钢筋仓位汇总库存达到 82.5%，右侧实时数据出现“钢筋仓位 07 达到演示预警关注线（82.5%）”。说明该告警是答辩演示中的固定模拟规则，并非现场实时报警。

## 互动与收尾

- 点击“重置”，确认库存回到 12,500t、任务回到 0%、告警清空；此举证明演示可复现。
- 点击龙门吊、筒仓或钢筋仓位可展示对象详情、数据来源和置信度。
- 如评审需要核验 CAD 关系，可打开“股道”“区域边界”；需要查看三维库存/人员标注时，再打开对应图层。

## 口径约束

- 车辆路线、设备精确位置和库存数值属于 `simulation` / `inferred` 演示数据。
- 已由总平面矢量图确认的区域保留 `site-plan-vector / confirmed` 来源。
- 规划转运区不能描述为已投产设施。
