3. 统一 REST 路径（/api/v1、/api/ehm/v1、/emcs-api 等目前不统一）；
4. 视频最终协议、ZLMediaKit 是否采用（待设备招标）；
5. EMCS → 底座接入方式（EMCS 自身不用 RocketMQ）；
6. RocketMQ 选型在接口评审会复核确认。
