## 二、核心设计：一份产物，根路径/子路径都能部署

- 所有静态资源（GLB、GeoJSON、Cesium 离线包、favicon）在运行时由 `import.meta.env.BASE_URL`
  拼接，构建时用 `base` 决定前缀：
  - 根路径：`pnpm build` → 资源为 `/models/...`、`/cesium/...`；
  - 子路径：`pnpm build -- --base=/dt/` → 自动变为 `/dt/models/...`，**无需改代码**。
- 后端默认同源 `/api/v1`，由 Nginx 反代到 Easegress；换网关地址只改 Nginx 或环境变量，不重新改代码。
- 完全离线：不依赖任何在线 CDN / Cesium ion 影像 / 在线字体。

## 四、到服务器怎么落地（两种方式，任选）

**方式 A（推荐，node6 直接构建）**：源码传到 node6 → `./deploy/build-and-deploy.sh`。
**方式 B（最省事，只传产物）**：本地已构建好 `apps/admin/dist`（另附 zip），scp 解压到
Nginx root（默认 `/usr/share/nginx/b-dt`），放入 `deploy/nginx-app-node.conf`，`nginx -t && systemctl reload nginx`。

## 五、需要你/老师确认的两处占位（不阻塞部署）

1. **Easegress 真实地址端口**：`nginx-app-node.conf` 的 `upstream b_dt_api` 现为占位
   `127.0.0.1:8080`，拿到 node4/node5 网关 IP:端口后改这两行即可。
2. **根路径还是子路径**：默认根路径；若要挂 `/dt/`，构建加 `--base=/dt/` 并按配置文件末尾注释调整 Nginx。

> 当前页面数据为本地 mock，可离线独立演示；后端接入后无需改前端，只调 Nginx 反代。
