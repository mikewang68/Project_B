# EMCS 范围快照增量

`001-central-scope.sql` 是原业务范围基础；`002-scoped-snapshots.sql` 为巡检汇总和费用重算申请补齐三个可空 VARCHAR(64) 归属字段。

应用顺序：先检查两个实际表存在、六新列尚未存在；记录库指纹、表结构/权限/索引/约束及旧行摘要；在事务中对两个表取得 ACCESS EXCLUSIVE NOWAIT 锁，再执行 002、核对六列类型/可空/无默认值及原结构与旧数据摘要，最后提交。已经存在列时先逐列核对契约，不盲目重复执行，不静默覆盖。

002 SHA256：`b1c7e64828b53c17d70f689adfa09752813ed33ddd384663be735190875e08a1`。脚本仅增列，无账号、种子、历史归属回填和清理语句。运行目标、备份和实际执行记录保存在私有运维交接包，不入源码。

写入归属由可信会话生成，单一有效范围记录具体三属性；全局明确范围以外的历史记录保持 NULL，区域用户不可见。巡检结果为 summary_only 的告警/建议计数汇总，不等于设备诊断完成；费用申请 REQUESTED_NOT_EXECUTED 不等于重算完成。

回退程序时保留兼容新列及已产生数据。仅在确认无新数据依赖且另行批准删除范围列时才拟定反向 DDL，不以旧整库备份覆盖新增业务记录。
