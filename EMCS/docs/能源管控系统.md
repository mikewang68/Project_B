# 能源管控系统功能菜单与实现现状

整理日期：2026-09-03  
适用项目：B 项目能源管控系统及 B-project-demo

## 1. 文档说明

本文汇总知识库现行需求和当前 demo 的功能，包含现有功能、待补功能及预留能力，供菜单设计、功能介绍和后续开发拆分使用。菜单分组为整理建议，不代表已修改系统导航，也不替代正式需求基线。

核对依据为知识库需求基线 v0.3.4、PRD v0.2.1，以及当前仓库的菜单种子、前端页面和后端业务代码。本次为静态核对，未启动系统进行运行验收。

| 状态 | 含义 |
| --- | --- |
| 已有 | 当前代码已有对应页面或功能；不等同于完整需求已通过验收。 |
| 部分已有 | 已有数据模型、计算服务、局部展示或部分流程，完整页面或管理能力尚待补齐。 |
| 待开发 | 知识库已有定义，当前未发现对应完整业务页面或实现。 |
| 预留 | 属于扩展范围或待评审能力，不作为当前已交付功能。 |

## 2. 当前 demo 已配置的能源业务入口

以下依据 `datagen/generate_demo_data.py` 的菜单种子配置整理。实际登录可见范围受角色授权和数据库初始化状态影响。

```text
│   └── 节能建议
├── 成本与报表
│   ├── 成本核算
│   └── 报表导出
└── AI 巡检

全局入口：智能问数
```

统计分析、作业能耗归因、采集点台账已有菜单种子，但当前配置为隐藏，不能算作已开放页面。用户、角色、日志、调度等通用管理页面位于系统基础框架中。

## 3. 完整功能菜单

## 6. 实现现状与后续补齐顺序

当前 demo 已形成五幕主线：能源总览 → 原始数据与质量 → 异常告警与设备画像 → 节能建议 → 成本核算与报表。代码中另有智能问数和 AI 巡检扩展。

建议后续按以下顺序完善。此处为菜单与功能完整性建议，不改变正式需求优先级和交付承诺。

1. 补齐采集点台账管理，使演示数据背后的用能对象可以维护。
2. 补齐独立统计分析、基线管理和作业能耗归因页面。
3. 补齐接口健康监控、规则配置和能源专用参数管理。
4. 完善审批、审计和角色数据范围的统一管理及验证。
5. 推进短期预测和移动端，并将 AI 扩展纳入正式需求追踪。
6. 预留能力按评审和启用条件进入后续范围。
