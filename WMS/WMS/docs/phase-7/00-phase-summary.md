# 阶段 7：财务、统计和集成实施与验收记录

## 1. 旧系统行为对照

本阶段以旧项目 `models/finance.py`、`blueprints/finance`、`blueprints/auth/views_async.py`、`blueprints/qimen` 和对应 Vue 页面为依据，保留以下业务含义：

- 费用区分收入/应收与支出/应付，并记录费用类型、合作伙伴、关联业务单和记账日。
- 每次收款或付款生成独立流水；全额结清进入完成状态，部分完结时剩余金额记为坏账。
- 提供月度收支、最近 12 个月趋势、合作伙伴余额、入库货品和出库货品统计。
- 导入导出以任务保存执行状态、文件、成功行数和错误信息。
- 奇门使用 2.0 风格参数排序 MD5 签名，支持商品同步、建单、取消、库存查询和完成回传。

## 2. 数据库与权限

迁移脚本：`database/migrations/V011__finance_reporting_integration.sql`，已在 openGauss 6.0.5 实际执行。

新增表：

- `finance_account`：收付款账户。
- `finance_money`：应收应付及其他费用主单。
- `finance_money_transaction`：实际收付款流水。
- `async_task`：Excel 导入导出任务。
- `integration_qimen_config`：按公司和货主保存的奇门配置，密钥不在查询接口中回显。
- `integration_qimen_log`：奇门接收和回传日志。

新增权限为 `finance:read`、`finance:write`、`integration:manage`；动态菜单为“财务统计”和“导入导出与集成”。所有查询继续使用当前公司、仓库和货主范围。

## 3. 后端与前端能力

### 财务

- 新增、修改和取消费用单。
- 登记多笔收付款，禁止超额、重复请求及已完结单继续付款。
- 全额完成、部分完成和坏账金额自动计算。
- 收付款账户新增、编辑和停用。
- 月度汇总、12 个月趋势、合作伙伴应收应付汇总、出入库货品统计。
- 财务页面包含指标卡、明细、账户、报表和 ECharts 6.1.0 趋势图。

### Excel 与任务

- 导出：货品、合作伙伴、库存、入库单、出库单、财务费用。
- 导入：货品、合作伙伴、入库单、出库单。
- 提供标准 `.xlsx` 模板；入出库导入结果为草稿单，不绕过正常库存作业。
- 后台异步执行，页面轮询任务的处理中、完成和失败状态；文件下载受 Session、权限和租户范围保护。

### 奇门

- 公共入口：`/open/qimen`（JSON）与 `/open/qimen/xml`（XML）。
- 支持 `singleitem.synchronize`、`entryorder.create`、`returnorder.create`、`stockout.create`、`deliveryorder.create`、`order.cancel`、`inventory.query`。
- 外部单号幂等；入出库仍使用系统内部业务单号。
- 支持人工触发入库/出库完成回传；只有配置回传地址后才会访问外部系统。
- 配置页面不回显密钥明文，每次请求和失败均记录日志。
