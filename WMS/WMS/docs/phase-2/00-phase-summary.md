# 阶段 2：登录、权限和租户

状态：已完成  
完成日期：2026-08-19

## 已实现

- 建立 `auth_company`、`auth_user`、角色、权限、用户角色、菜单及用户数据范围表。
- 建立仓库和货主最小主数据；完整字段在阶段 3 扩展。
- 使用 Spring Security HttpSession 保存认证状态，登录时更换 Session ID。
- 启用 Cookie CSRF 防护，Vue 写请求显式携带后端签发的令牌。
- 新密码使用 BCrypt strength 12；兼容旧系统 SHA-256 密码，并在首次登录成功后自动升级。
- 保留旧系统的公司、仓库、货主三级上下文语义；管理员可访问公司全部范围，普通用户只能访问已授权范围。
- 后端按权限生成动态菜单；前端路由守卫和后端方法权限同时校验。
- 实现登录、退出、当前用户、切换仓库/货主、修改密码接口。
- 实现公司内用户列表、新建、编辑、启停、角色、仓库和货主授权维护。
- 防止管理员从用户列表停用或修改自己的当前登录账号。

## 数据库迁移

- `V003__auth_tenant_and_menu.sql`：认证、RBAC、菜单、租户上下文及本地种子数据。
- `V004__application_sequence_privileges.sql`：应用账号自增序列最小权限。
- V001～V004 均已登记到 `schema_version`，重复执行会安全跳过，校验值变化会被拒绝。
