# 阶段 3：仓库基础资料

状态：已完成  
完成日期：2026-08-19

## 旧系统行为保留

- 新建仓库自动创建默认库区、默认工作区和 `STAGE` 暂存库位。
- 新建货主自动创建默认货类。
- 库区、工作区和库位始终受当前仓库约束。
- 货类、货品和组合件始终受当前货主约束。
- 同一仓库、货主或公司范围内的业务编码不可重复。
- 货品条码在当前货主范围内唯一；留空时默认使用货品编码。

## 新结构

- 扩展 `wms_warehouse` 和 `wms_owner` 联系信息。
- 新建 `wms_area`、`wms_work_area`、`wms_location`、`wms_partner`。
- 新建 `wms_category`、`wms_good`、`wms_good_component`。
- 所有旧字符串关联均改为公司、仓库、货主及主数据外键。
- 新建 `wms_business_sequence`，按公司、仓库、货主、前缀和年月加锁递增。

## 接口与页面

- `/api/v1/master-data/{resource}` 提供八类主数据和组合件的查询、新建、更新。
- `/api/v1/sequences/{prefix}/next` 提供业务单号生成。
- 动态菜单新增“基础资料”。
- 基础资料页面包含仓库、库区、工作区、库位、货主、合作伙伴、货类、货品和组合件九个标签页。

## 数据库迁移

- `V005__warehouse_master_data.sql`：仓库基础资料、权限、菜单及默认资料。
- `V006__business_sequence.sql`：租户范围业务单号序列表。
