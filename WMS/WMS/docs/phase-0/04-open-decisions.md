# 待确认事项与阶段门禁

这些事项按对应业务阶段确认，不影响独立工程骨架继续开发。

| ID | 事项 | 临时方案 | 责任方/完成门 |
|---|---|---|---|
| DEC-001 | openGauss数据库是否采用B兼容模式 | 独立 `mt_wms` 数据库，SQL按6.0.5实测 | 阶段1数据库初始化前 |
| DEC-002 | 旧用户密码是否可直接兼容 | 先保留迁移接口，不复制明文密码 | 阶段2登录迁移时 |
| DEC-003 | `mes`、`share` 调用的真实目标和保留范围 | 不猜测，不纳入阶段1 | 相关业务阶段前 |
| DEC-009 | 旧财务 `partdone` 的准确业务口径 | 暂译“部分结算” | 财务业务负责人，阶段 7 前 |
| DEC-010 | 旧配置项默认值与弃用项 | 迁移语义清单，不直接定生产值 | 每个业务阶段验收时 |

## 已接受的本地环境限制

- 当前机器Node.js 24.x、pnpm 11.19.0可用。
- 当前默认 Java 是 8、Maven 是 3.8.6，不满足 Java 17/Maven 3.9.x 基线。阶段 1 可以创建代码，但完整 Maven 构建必须切换到合规工具链后验收。
