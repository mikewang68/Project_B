# VEGAPULS 6X 独立只读参考配置（0.4.0）

用途：筒仓雷达子设备的原始协议联调。不是现场整机点表、原厂固件仿真或公共底座事件。原五通道及EE600保留，110点CSV／JSON／C定义不改。

依据：[VEGA原厂手册1015559-EN-250117，2025-01-17](https://www.vega.com/api/sitecore/DocumentDownload/Handler?documentContainerId=1008946&documentGroupId=1015559&fileExtension=pdf&languageId=2&version=17-01-2025)。本地固定PDF SHA256为768e924608b58f04028d60b5067a2d7dfb1fc41cd086f82582cb9ecf268a084b；58–60页为距离／空满标定，130–134页为通信／寄存器，139页为主机地址基数。

## 连接与已实现地址

Android“仪表”→“VEGAPULS 6X 雷达”，保存参数；“连接”→启动USB／仅本机服务。19064为原始Modbus RTU字节的TCP隧道，无MBAP，不模拟RS485电气及字符间隔。站号246参考原厂默认值；9600/8N1为原厂串口默认，隧道不实际执行波特率。一次一个连接，空闲或截断请求约2秒关闭。

| 表／功能码 | PDU地址（十进制） | 字数 | 编码和用途 |
|---|---:|---:|---|
| 输入／FC04 | 100、2000 | 各2 | DWORD状态；bit0=PV无效，bit1–3=SV/TV/QV无效 |
| 输入／FC04 | 104 | 2 | DWORD PV单位代码；45=m、44=ft、43=m³等 |
| 输入／FC04 | 106 | 2 | Float32 CDAB PV |
| 输入／FC04 | 2002 | 2 | Float32 ABCD PV；可用2000起4字同时读取状态和PV |
| 保持／FC03 | 200 | 1 | 本模拟器固定站号246，只读 |
| 保持／FC03 | 3000 | 1 | 本模拟器固定格式代码0，只读 |

**状态及单位DWORD采用高字在前是本模拟配置约定。** 手册没有独立说明这两类整数的字序，尚无实物抓包验证，不能声称该约定已由原厂确认。PV的106=CDAB、2002=ABCD有明确手册依据。默认状态14仅表示PV有效、未模拟的SV/TV/QV无效；不是完整健康状态或NE107诊断。

PDU地址直接用表内100、104、106、2000、2002；按139页主机基数另行换成工具显示编号，不统一减1。手册2202行写BACD而格式代码3写BADC，故2202及配置字序的1302均未开放。SV/TV/QV、其它未实现配置地址返回异常02；写05/06/0F/10返回01；零计数或超过125字返回03。手册133页“1–127(0x7D)”文字互相矛盾，本子集按0x7D=125限制；FC03/04正常响应使用标准单字节Byte Count，不沿用表内“2 Bytes”的排印问题。坏CRC、站号不符及广播不响应；不冒充设备时间、序列号或固件信息。

## PV、质量和标定

原厂DTM可改变PV物理量，单位m也不能单独证明其为“传感器到料面的距离”。默认PV12.9、单位45、空距35m、满距1m均为参考样例；“已明确PV为距离”和“启用标定”默认关闭。空满样例来自手册59页散料示意，不是本项目仓体实测。

只有显式确认距离语义、启用有效标定、单位属于m/ft/in/cm/mm、PV有限且bit0未置位时，才计算：`料位%=100×(空距B−距离m)/(空距B−满距A)`。单位先换成m。超出[A,B]不钳位为0或100，百分比缺失；单位m³、温度或未知代码也不得计算。没有仓容曲线和容重，本模式不输出吨数。

无效bit0置位时，即使报文内仍是有限PV，受理值为null/BAD；NaN/Inf同样null/BAD。正常值及派生料位保持UNCERTAIN；尚未实机核对物理量、字序与标定，不能提升为GOOD。原协议没有测量源时间，本地报告source_ts_ms=null，独立记录网关观测时间。

## 参考读取

```powershell
adb -s 实际Android序列号 forward tcp:19064 tcp:19064
python vega_client.py --output runtime/vega-unconfigured
# 仅当本次参考试验明确PV=距离且采用35m/1m标定：
python vega_client.py --pv-meaning distance --empty-m 35 --full-m 1 --output runtime/vega-calibrated
```

客户端先读104单位，再一次读2000状态＋PV，最后复读104并核对单位未变；这不能替代现场多寄存器快照或并发配置锁，正式采集期间应冻结配置。CLI标定参数是操作者显式提供的元数据，原厂标定寄存器没有在本子集中虚构出来。只有在Android页和采集端元数据一致时比较派生值。

输出vega6x.reference.v1，保存每次请求、响应、CRC验证和观测时间；不调用gateway.py的110点转换，也不写公共底座、WMS或库存。
