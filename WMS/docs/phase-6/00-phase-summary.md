# 阶段 6：出库

状态：已完成  
完成日期：2026-08-20

## 旧系统行为保留

- 出库单保留创建、库存分配、拣货、装箱和发运作业链路。
- 保留销售、生产、普通、采购退货、协作、领料、维修、报废、借用、调拨、寄售和自定义出库类型。
- 库存不足时可按作业选择拒绝整单或允许部分分配。
- 支持整单快速拣货、按条码扫码拣货和 RFID/唯一标签拣货。
- 未发运时可取消分配，已分配数量全部归还可用库存；已发运单据不允许取消。
- 强制完成会发运已拣数量、释放未拣已分配数量，再关闭单据。
- 波次至少组合两张未分配出库单，支持整波分配和整波拣货。
- 调拨出库自动创建目标调拨入库单，取消未作业调拨出库时同步取消对应入库单。
- 已完成出库单可生成一张以实际发运量为计划量的退库入库单。

## 数据模型与状态

- `stockout_order` / `stockout_order_line`：出库单头和多货品明细，分别保存计划、分配、拣货和发运数量。
- `stockout_allocation`：出库明细与库存余额行的分配关系。
- `stockout_event`：分配、取消分配、拣货、装箱、发运、取消、完成和反单作业流水。
- `stockout_package` / `stockout_package_line`：包裹、承运商、运单号和装箱明细。
- `stockout_wave` / `stockout_wave_order`：波次及其包含的出库单。
- `stockout_serial_pick`：出库单与 RFID/唯一标签关联，取消分配时可恢复标签状态。
- 主状态为 `DRAFT → PROCESSING → COMPLETED`，未发运单据可转为 `CANCELLED`。
- 分配、拣货和发运分别使用 `NO / PARTIAL / FULL` 状态。

## 库存一致性

```text
分配：可用量 -N，已分配量 +N，总量不变
拣货：记录作业和标签，库存仍处于已分配量
发运：已分配量 -N，总量 -N
取消分配：已分配量 -N，可用量 +N，总量不变
```

- 分配时按失效日期、生产日期和库位作业顺序优先分配。
- 库存余额、出库单、分配明细、作业流水和库存流水在同一 Spring 事务内提交。
- 对出库单、明细、分配行、库存余额和 RFID 使用 `FOR UPDATE` 行锁。
- 创建、分配、拣货、装箱、发运、取消、完成、反单和波次作业均校验幂等键。

## 接口与页面

- `/api/v1/stockout`：出库单列表和创建。
- `/{id}/allocate|pick|pick-all|ship`：分配、扫码拣货、快速拣货和发运。
- `/{id}/packages`：包裹和装箱明细查询/创建。
- `/{id}/cancel-allocation|cancel|complete|reverse`：取消分配、取消单据、强制完成和生成退库单。
- `/waves` 及 `/waves/{id}/allocate|pick`：波次查询、创建、整波分配和整波拣货。
- 出库页面提供订单/波次双标签、汇总卡、多明细建单、分配台账、包裹台账、作业流水和全部核心作业入口。
