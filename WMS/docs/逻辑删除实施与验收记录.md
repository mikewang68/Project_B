# WMS 逻辑删除实施与验收记录

实施日期：2026-10-12；提交整理日期：2026-10-13。

## 改造范围

检查发现，原入出库及财务单据已有取消、反单机制，保留历史账据；但用户授权重配会物理删除三类授权关系，取消拣货会物理删除标签关联。基础资料和用户此前没有完整的删除接口及页面操作。本次补齐逻辑删除，并替换上述物理删除路径。

| 对象 | 删除或撤销方式 | 查询与使用规则 |
| --- | --- | --- |
| 仓库、货主、区域、作业区、库位、往来单位、分类、货品、组合关系 | 状态置为 `DELETED`，保存 `deleted_at`、`deleted_by` | 日常列表、业务选择和基础资料导出排除已删除项 |
| 用户 | 状态置为 `DELETED`，关闭登录，保存删除时间与操作人 | 用户列表隐藏；禁止登录；下一次 API 请求使旧会话失效 |
| 用户角色、仓库、货主授权关系 | 写入 `revoked_at`；再次授权重新激活保留行 | 权限计算仅使用未撤销关系及有效业务范围 |
| 出库标签拣货关联 | 写入 `cancelled_at`；再次拣货新增有效关联 | 取消与恢复库存仅处理有效关联，历史关联保留 |
| 库存、财务流水及入出库单 | 沿用原有取消、反单流程 | 保留历史账据，不提供直接删除 |

停用与删除分别处理：维护列表仍显示停用资料，便于重新启用；已删除编码继续占用，普通编辑、重复创建或 Excel 导入不能恢复已删除资料。历史账据保留关联名称，避免破坏追溯。

## 权限、引用与并发约束

- 基础资料删除接口：`DELETE /api/v1/master-data/{resource}/{itemId}`，要求 `master:write`，遵守当前公司、仓库、货主范围。
- 用户删除接口：`DELETE /api/v1/system/users/{userId}`，要求 `system:user:write`；禁止删除当前登录账号。
- 前端增加删除确认及权限控制；后端独立校验权限、业务范围和引用。
- 已有库存、单据或其他有效资料引用的基础资料拒绝删除，应使用停用。系统默认资料受保护；删除空仓库、货主时，未使用的内置资料同时标记删除。
- 每次 API 请求重新验证账号和当前授权。删除或停用账号、撤销权限后，旧会话不能继续使用原权限。
- 删除时锁定父记录并检查引用；数据库触发器在新增或变更引用时共享锁定父记录，拒绝引用已删除资料，避免并发绕过。
- 应用数据库账号撤销表 `DELETE` 权限；数据库管理员仍可进行受控专项维护。

## 数据库迁移与部署

迁移文件：`database/migrations/V015__logical_deletion.sql`。

新增 26 个字段：组合关系 `status`、`updated_at`，十张资料/用户表的删除时间与操作人，三张授权关系表的撤销时间，标签拣货关联的取消时间。数据库仍为 52 张表，字段总数由 620 增至 646。出库标签关联改用仅覆盖有效行的唯一索引，允许保留多次取消历史。

部署顺序为：备份数据库与现用程序，停止 WMS，按既有迁移工具执行 V015 并记录版本，安装新版程序，再启动与检查健康。不要只更新程序而遗漏数据库迁移。

实验室现网于 2026-10-12 部署完成，WMS 服务及数据库健康检查通过；52 张表的部署前后记录数对比中，仅迁移版本表增加一行，原有业务记录数量不变。共享源码已同步，GitHub 提交仅涉及 `WMS/WMS`。

上线后如需回退，须同时评估数据库权限、有效行索引及已产生的撤销/取消历史，不能直接替换旧 JAR。优先修复并向前部署；整库恢复须单独制定恢复方案，避免覆盖上线后的正常业务记录。

## 验证结果

前端 16 项测试、Java 16 项测试通过，构建成功。隔离 openGauss 数据库完成以下 14 组验证：

1. 隔离数据库登录。
2. 往来单位删除后保留记录、列表隐藏，旧编辑和重复编码被拒绝。
3. 库位层级不得引用已删除父资料，存在有效子资料的父项受到保护。
4. 货品、分类和组合关系删除及引用检查。
5. 跨公司删除被拒绝。
6. 授权撤销保留关系行，旧会话失去对应权限；再次授权可生效。
7. 删除用户后列表隐藏，密码登录及旧会话被拒绝，禁止自删。
8. 实际入库、标签拣货、取消分配、重新拣货及取消出库，历史关联保留；库存引用货品不能删除。
9. 空仓库、货主及未使用内置资料逻辑删除，业务范围列表过滤。
10. 应用账号没有表物理删除授权。
11. Excel 导出包含有效货品、排除已删除货品。
12. Excel 导入已删除编码失败并明确结束任务，不恢复资料。
13. 使用实际应用账号直接执行物理删除或插入无效引用，数据库拒绝。
14. 并发删除父资料时，新增无效引用被阻止。

现网 HTTPS 登录、基础资料、库存及入库单查询验证通过，原有演示数据可见。验证使用独立测试数据库，不在现网创建或删除测试业务数据；测试进程及测试数据库已清理。
