# Project_B

数字孪生 / 综合监控一体化项目集合（多子系统合集）。

## 子系统

| 目录 | 说明 |
|------|------|
| `DTS/`  | 数字孪生系统（Digital Twin System） |
| `EHMS/` | 设备健康管理系统 |
| `EMCS/` | 能源管理与控制系统 |
| `IAM/`  | 身份与访问管理前端 |
| `PSMS/` | 生产调度管理系统 |
| `SCS/`  | 安全卡控系统 |
| `WMS/`  | 仓储管理系统 |

## 平台公共能力

| 目录 | 说明 | 状态 |
|------|------|------|
| [TRUST/](TRUST/README.md) | 可信存证与溯源：事件台账、IPFS 归档、Fabric 存证、失败补办、件料溯源、核验导出 | v0.1.0 开发联调版 |

TRUST 采用独立组件部署；源码、配置模板、模拟样例和脱敏验收摘要见模块 README。真实业务系统接入和剩余验收范围在模块文档中分别说明。

## 快速开始

各子系统独立构建与运行，请进入对应目录查看 README。

```bash
# 示例：进入 IAM 前端
cd IAM && pnpm install && pnpm dev
```

## 注意事项

- 大型 CAD/模型/构建产物已通过 `.gitignore` 排除
- 各子目录保留各自原有的 `.gitignore` 规则
- 请勿提交 `.env` 等含密钥的文件
