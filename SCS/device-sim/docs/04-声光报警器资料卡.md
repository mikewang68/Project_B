## 3. 连接与协议

- **Modbus TCP**，端口默认 15040，单元 ID 1；写=FC06/FC16（Holding Register），读=FC03。
- 只读 DO 继电器形态（无网口款）为并行能力，本卡与模拟器以 Modbus TCP 为准（与 S3 接口条件一致）。

## 4. 点位与报文（寄存器映射）

| 寄存器 | 来源 | 含义 |
|---|---|---|
| 0x0000 | **原厂风格**（LA6-POE Unit Control） | 灯位控制位图：bit0=红、bit1=琥珀(橙)、bit2=黄位沿用扩展、bit3=绿、bit4=蓝、bit5=白（S3 黄/橙/红 使用 bit2/bit1/bit0；闪烁模式经 0x0010 pattern 区设定） |
| 0x0001 | **原厂风格**（Buzzer Control） | 蜂鸣声调 pattern 0~11（0=关；1=常鸣；2=断续…详见原厂手册 pattern 表） |
| 0x0002 | **构造扩展** | 持续时长（秒，0=直至清除） |
| 0x0003 | **构造扩展** | 防抖抑制窗口（ms，默认 500） |
| 0x0010 | **原厂风格** | 红/橙/黄 pattern（0=灭 1=常亮 2=闪…） |
| 0x1000 | **构造扩展（回执区，只读）** | 当前激活颜色枚举：0=无 1=黄 2=橙 3=红 |
| 0x1001 | **构造扩展（回执区）** | 剩余时长（秒，倒计时，0=空闲） |
| 0x1002 | **构造扩展（回执区）** | 最近触发序号（每次有效触发 +1，供 S3 回执对账） |
| 0x1003 | **构造扩展（回执区）** | 防抖抑制计数（窗口内被合并的触发次数） |

S3 联动语义映射：预警=黄(bit2)、严重=橙(bit1)、紧急=红(bit0)+蜂鸣 pattern≥1；灯色/声调/时长三要素一条指令经 FC16 一次写入（0x0000~0x0003 连续区）。

## 5. 时间与异常

- 下行触发瞬时生效；持续时长倒计时归零自动熄灭并清回执区剩余时长。
- 防抖：0x0003 窗口内重复写 0x0000 触发被合并（回执序号不变、0x1003 计数+1）——对应清单"防抖抑制"。
- 异常：写入值超 pattern 范围 → 从机返回 ILLEGAL_DATA_VALUE（0x03）异常码，网关按错误处理，不静默忽略。

## 6. 替代差异声明

寄存器布局为"LA6-POE 原厂风格（0x0000/0x0001/0x0010）+ 我方构造扩展（时长/防抖/回执区）"。现场若选 DO 继电器款（无 Modbus），则整个控制面退化为干接点，映射层需重做。**仅辅助示警与回执**：本设备不承载任何重型设备控制。
