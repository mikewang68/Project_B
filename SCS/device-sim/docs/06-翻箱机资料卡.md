| 项 | 内容 |

## 3. 连接与协议

- 形态：**Modbus TCP 从站**（MBAP + PDU），单元 ID 1，端口默认 **15060**。
- 读：FC03。写：仅 0x0100 场景切换（FC06），正式设备无此寄存器。
- 频率：模拟器内部 20Hz 刷新；液压动作是秒级过程，网关 1~2Hz 轮询足够。

## 4. 点位与报文（寄存器映射）

**全部为构造扩展**（无原厂依据），UInt16，高字节先：

| 寄存器 | 含义 | 换算 | 取值范围 |
|---|---|---|---|
| 0x0000 | 作业阶段 | 枚举 | 0=待机 1=箱体就位 2=举升中 3=倾卸中 4=回落 5=故障 |
| 0x0001 | 行走速度 | — | 固定工位，恒为 0（保留字段，与龙门吊对齐） |
| 0x0002 | 方向 | — | 固定工位，恒为 0 |
| 0x0003 | 箱重 | ÷10 → t | 0~400（0~40.0 t） |
| 0x0004 | 举升角度 | ÷10 → ° | 0~1500（0~150.0°） |
| 0x0005 | 液压系统压力 | ÷10 → MPa | 0~350（0~35.0 MPa） |
| 0x0006 | PLC 联锁 | 枚举 | 0=不可用 1=可用 |
| 0x0007 | 设备健康码 | 枚举 | 0=NORMAL 1=DEGRADED 2=DOWN |
| 0x0100 | 场景切换 | 枚举，仅 FC06 | 构造，正式设备无 |

## 5. 场景

| 场景 | 语义 | 寄存器表现 |
|---|---|---|
| `idle` | 待机 | 阶段=0，角度=0，压力≈2.0 MPa，箱重=0 |
| `dump` | 完整作业循环 | 就位(1) → 举升中(2，角度 0→135°) → 倾卸中(3，角度保持) → 回落(4，角度→0) → 待机，约 40s 一轮 |
| `blocked` | 堵料卡阻 | 阶段=2 或 3 时角度停滞、压力升到 28~32 MPa（超正常工作压力），健康=DEGRADED |
| `fault` | 故障 | 阶段=5，健康=DOWN，联锁=0，角度停在当前值 |

## 6. 时间与异常

- 寄存器无源时间戳 → 网关提供观测时间，`source_ts_ms=null`、`timestamp_origin=gateway_observation`。
- **堵料是翻箱机最典型的异常**：角度不增而压力持续升高。SCS 侧可据此判「作业受阻」，
  当前只做状态展示与健康降级，告警规则后续接入。
- `fault` 场景角度保持最后值而非归零——真实设备故障时机构会停在半途，归零反而是错误表达。

## 7. 替代差异声明

本卡所有寄存器地址与换算**均为我方构造**。设备选型确定后需：
1. 按实际手册替换第 4 节地址表；
2. 确认是否区分「举升角度」与「翻转角度」两个量（部分机型有二级翻转）；
3. 确认液压压力的正常区间（本卡 2~32 MPa 为估计值）。
在此之前，本模拟器仅用于联调演示，**不得作为现场接线或 PLC 点表依据**。
