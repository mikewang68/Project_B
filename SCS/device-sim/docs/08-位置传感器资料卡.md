# 【设备协议资料】装卸区 B 位置传感器｜敬昌隆

版本：v0.1，2026-10-28。调研负责人：敬昌隆（安全卡控 S3）。

> **重要**：现场设备**未采购、无厂家手册**。寄存器映射**全部为我方构造**，
> 不得作为现场接线或 PLC 点表依据。设备到位后按实际手册替换第 4 节。

## 1. 对应原表

- 组会第十七次纪要：议题二「装卸区 B 研究位置传感器或门禁开关获取车辆进出状态，**至少能够判断有无车辆**」。
- 现场型号：**待选型确认**。

## 2. 方案选型理由

装卸区 B 的最低要求是「有没有车」，位置传感器能同时给出**连续测距**，比门禁多一层信息：

| 方案 | 判断有无车 | 额外信息 | 主要问题 |
|---|---|---|---|
| **位置传感器（选定）** | ✅ 测距 ≤ 阈值即有车 | 距离、可做驶入/驶离趋势 | 需选量程与安装角，避免误检相邻车道 |
| 门禁/地感线圈 | ✅ 有车 | 无距离 | 只能给出占用位，无法区分车型/位置 |
| 视觉 | ✅ | 车型、车牌 | 成本高，受光照与遮挡影响 |

选位置传感器是因为它**同时满足「至少判断有无车」和后续可扩展的驶入/驶离判定**。

## 3. 连接与协议

- 形态：**Modbus TCP 从站**，单元 ID 1，端口默认 **15080**。
- 读：FC03。写：仅 0x0100 场景切换（FC06），正式设备无此寄存器。
- 频率：模拟器 20Hz 刷新；车辆进出是秒级过程，网关 2~5Hz 轮询足够。

## 4. 点位与报文（寄存器映射）

**全部为构造扩展**，UInt16，高字节先：

| 寄存器 | 含义 | 换算与取值 |
|---|---|---|
| 0x0000 | 测距 | mm，量程 0~10000（10m）；0 且健康 DOWN 表示无效读数 |
| 0x0001 | 车位状态 | 0=无车 1=有车 2=故障 |
| 0x0002 | 设备健康码 | 0=NORMAL 1=DEGRADED 2=DOWN |
| 0x0100 | 场景切换 | 构造，仅 FC06 |

**有车判定阈值：测距 ≤ 3000mm。** 该阈值是构造值——实际取决于安装高度、
车身长度与停位偏差，选型后必须现场标定。

## 5. 场景

| 场景 | 语义 | 寄存器表现 |
|---|---|---|
| `empty` | 车位空 | 距离 8500mm，状态=无车 |
| `arrive` | 车辆驶入 | 30s 周期：0~15s 由 9m 递减到 2.4m，之后保持；越过 3m 阈值时状态翻为有车 |
| `occupied` | 车已停稳 | 距离 2400mm，状态=有车 |
| `depart` | 车辆驶离 | 30s 周期：0~15s 由 2.4m 递增到 9m，之后空位 |
| `fault` | 传感器故障 | 距离 0，状态=故障，健康 DOWN |

## 6. 时间与异常

- 寄存器无源时间戳 → 网关提供观测时间，`source_ts_ms=null`。
- **故障与"有车"在距离上都会读到 0**：只看 0x0000 会把故障当成车贴脸。
  必须结合 0x0002 健康码判定，这与限位开关的坑同源。
- 驶入/驶离的**事件**（进入时刻、离开时刻）由网关侧状态机从距离序列导出，
  寄存器只给瞬时量；SCS 只展示当前有无车与测距，不做事件推断。

## 7. 替代差异声明

全部寄存器地址与换算为我方构造。选型确定后需确认：
1. 实际接口（Modbus RTU / IO-Link / 4-20mA 经采集模块）；

3. 有车阈值需现场标定，本卡的 3000mm 仅为占位。
