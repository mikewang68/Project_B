## 3. 连接与协议

- 形态：**Modbus TCP 从站**（MBAP + PDU），单元 ID 1，端口默认 **15050**。
- 读：FC03（保持寄存器）。写：仅 0x0100 场景切换（FC06），**正式设备无此寄存器**。
- 频率：模拟器内部 20Hz 刷新寄存器；网关按需轮询 1~5Hz 即可。
- 选 Modbus TCP 的理由：与已有雷达/声光模拟器同源（复用 `common/modbus_tcp.py`），
  且起重机 PLC 对外暴露 Modbus TCP 是常见形态。**若实际为 OPC UA / Profinet，本层需重写，数据项不变。**

## 4. 点位与报文（寄存器映射）

**全部为构造扩展**（无原厂依据），UInt16，高字节先：

| 寄存器 | 含义 | 换算 | 取值范围 |
|---|---|---|---|
| 0x0000 | 运行状态 | 枚举 | 0=待机 1=作业中 2=故障 3=检修 |
| 0x0001 | 大车行走速度 | ÷10 → m/min | 0~600（0~60.0 m/min） |
| 0x0002 | 大车运行方向 | 枚举 | 0=停止 1=向东 2=向西 |
| 0x0003 | 吊具载重 | ÷10 → t | 0~500（0~50.0 t） |
| 0x0004 | 起升高度 | ÷10 → m | 0~300（0~30.0 m） |
| 0x0005 | 风速 | ÷10 → m/s | 0~600（0~60.0 m/s） |
| 0x0006 | PLC 联锁 | 枚举 | 0=不可用 1=可用 |
| 0x0007 | 设备健康码 | 枚举 | 0=NORMAL 1=DEGRADED 2=DOWN |
| 0x0008 | 小车位置 | ÷10 → m | 0~400（0~40.0 m） |
| 0x0100 | 场景切换 | 枚举，仅 FC06 | 构造，正式设备无 |

示例帧（TCP，MBAP 头 + PDU，无 CRC）：
读 0x0000~0x0007 共 8 个寄存器 → 请求 `0001 0000 0006 01 03 0000 0008`，
应答 `0001 0000 0013 01 03 10 <16 字节数据>`。

## 5. 场景

| 场景 | 语义 | 寄存器表现 |
|---|---|---|
| `idle` | 待机 | 状态=0，速度=0，方向=0，载重=0 |
| `hoist` | 起升作业 | 状态=1，载重 0~32t 周期性变化，起升高度往复 |
| `travel` | 大车行走 | 状态=1，速度 0~45 m/min，方向东西往复，小车位置联动 |
| `wind` | 风速超阈值 | 状态=1，风速 120~180（12~18 m/s，超 6 级风作业限值） |
| `fault` | 故障 | 状态=2，健康=DOWN，联锁=0，其余归零 |

## 6. 时间与异常

- 寄存器无源时间戳 → 网关提供观测时间，`source_ts_ms=null`、`timestamp_origin=gateway_observation`。
- 异常表达：`fault` 场景下 `health=DOWN`，网关应把该设备标记为不可用而不是沿用上一次数值。
- 风速超限属于**安全联锁输入**，SCS 侧应能据此产生告警；当前仅作数据展示，告警规则由业务侧后续接入。

## 7. 替代差异声明

本卡所有寄存器地址与换算**均为我方构造**，与任何实际起重机 PLC 无关。设备选型确定后需：
1. 按实际手册替换第 4 节地址表；
2. 确认通信形态（Modbus TCP / OPC UA / Profinet / 厂家私有协议）；
3. 确认是否有源时间戳、是否需要写控制字（本轮只读）。
在此之前，本模拟器仅用于联调演示，**不得作为现场接线或 PLC 点表依据**。
