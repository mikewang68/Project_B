## 3. 连接与协议

- 事件方向（盒→消费方）：**HTTP Webhook POST**（盒主动推送到注册的回调 URL，Content-Type: application/json）；一次事件一帧。
- 抓拍图：盒内置 HTTP 服务 `GET /snapshots/{eventUuid}.jpg`（JPEG）；事件 JSON 中给绝对/相对 URL，消费方按 URL 拉取。
- 默认端口：盒 HTTP 服务 15030；webhook 目标由 `--webhook-url` 指定（联调时指向网关/本地接收器）。

## 4. 点位与报文

事件 JSON（DeepStream 风格骨架 + S3 清单字段集；`@` 前缀为 DeepStream schema 原生字段，其余为 S3 消费字段）：

```json
{
  "@schema": "nvidia/deepstream/eventmsg/v1",
  "eventUuid": "a3f8c2e1-7b4d-4c2a-9e1f-112233445566",
  "eventType": "entry",
  "objectType": "person",
  "objectConfidence": 0.94,
  "cameraCode": "CAM-03",
  "violationType": "NO-HELMET",
  "snapshotUrl": "http://<box-ip>:15030/snapshots/a3f8....jpg",
  "zoneId": "FENCE-03",
  "ts": "2026-10-24T21:00:05.120+08:00",
  "simulated": true
}
```

- `violationType` 枚举严格对齐 S3 清单：`NO-HELMET` / `NO-VEST` / `ZONE-INTRUSION`。
- `objectConfidence` ∈ [0,1]（S3 侧阈值 0.85 起进入复核，与后端既有规则一致）。
- `eventUuid` 全局唯一（幂等键）；重复推送同一 UUID，S3 侧按 eventUuid 去重。
- `simulated: true` 贯穿（底座契约要求）。

## 5. 时间与异常

- `ts` 为盒端源时间（ISO-8601 带时区），S3 以此为 occurredAt。
- 异常场景：`duplicate`（同 UUID 重发，验证幂等）、`low-confidence`（0.62，S3 应标"不确定"不建单）、`burst`（短时多事件，验证防抖/合并）。
- 抓拍图：模拟器用 PIL 生成带时间水印的合成 JPEG（约 1~3KB），**不是真实抓拍**。

## 6. 替代差异声明

DeepStream schema 是容器/消息骨架参考，非具体整机型号；海康/大华事件回调、华为 iCube 等私有格式各异。现场选型后仅需替换 webhook 字段映射层。抓拍图 URL 的鉴权方式（签名/令牌）未定，模拟器当前无鉴权，**不能据此推定生产也无鉴权**。

## 7. 模拟与联调

- 模拟器：`device-sim/aibox/aibox_sim.py`（纯标准库 + 可选 PIL；无 PIL 时输出 1×1 像素 JPEG 常量）。
- 场景种子：`helmet`（NO-HELMET 0.94）、`vest`（NO-VEST 0.88）、`intrusion`（ZONE-INTRUSION 0.91）、`mixed`（三类轮转+低置信度+重复）。
- 已覆盖：webhook 推送、快照服务、幂等 UUID、低置信度、burst。未覆盖：RTSP 取流、真实推理、MQTT 出口形态。
