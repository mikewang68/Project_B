## 一、系统建设背景与总体架构

## 二、各自模块全量功能清单

系统遵循企业级工业 SaaS 规范，各业务子模块及其细分功能特性清单如下：

### 2.1 安全态势中心（全局总览与全屏大屏）
* **模块路径**：`/overview`（总览）、`/safety-screen`（全屏大屏）
* **核心功能清单**：
  1. **核心安全指标实时看板**：在岗作业人员总数、在线作业设备数、今日告警发生总数、待处理事件数、高风险拦截事件数；
  2. **高精度货场态势地图拓扑**：集成装卸区 A/B、龙门吊作业区、翻箱机作业区、铁路专用线、车辆通道、临时检修区等多边形物理边界与实时热区标定；
  3. **实时作业要素动态呈现**：人员点位位置、特种设备实时坐标、电子围栏高亮边框；支持正常（绿）、预警（黄）、高危（红）三态动态渲染；
  4. **全生命周期实时告警 Feed 流**：集成实时告警推送流，支持按紧急（URGENT）、严重（SEVERE）、警告（WARNING）、普通（NORMAL）四级分级渲染，点击直接拉起处置抽屉；
  5. **安全风险交互式仿真验证**：内置“人员误入龙门吊盲区”风险模拟发生器，触发后人员 Marker 产生 Pulse 动效、实时建单并在地图与告警流中同步生效，支持重复复位与推演；
  6. **沉浸式暗色工业全屏大屏**：提供 1920×1080 / 4K 独立展示终端模式，支持图表自适应缩放、边缘网关与传感器健康度拓扑展示。

### 2.2 人员定位与参数化配置模块
* **模块路径**：`/people`
* **核心功能清单**：
  1. **作业人员列表检索与多维筛选**：支持姓名、工号、所属班组（装卸一班/二班/维保组/外协单位）、作业区域、人员在岗状态、手环连接状态筛选；
  2. **人员卡片与空间位置联动**：点击人员列表项在货场二维地图中自适应平移并高亮目标，展示实时坐标 $(X, Y)$、定位信噪比、基站信号强度；
  3. **智能穿戴手环健康管理**：实时采集并监控手环电量（支持 `< 20%` 低电量告警）、手环脱落判定、离线判定及静止超时预警；
  4. **历史移动轨迹回放**：支持选择历史时间段回放作业人员作业轨迹，呈现行进路线、停留时长、速度波动及越界经过标记；
  5. **人员定位刷新频率在线配置（本周新增）**：
     * 支持通过前台弹窗/配置面板在线设置人员定位刷新时间间隔（支持 `1s ~ 60s` 范围，默认 `3s`）；
     * 后端提供参数合法性强校验并持久化，即时生效并通过 WebSocket 向各端同步推送定位刷新节拍。

### 2.3 动态电子围栏与外围逻辑缓冲区模块
* **模块路径**：`/fences`
* **核心功能清单**：
  1. **多边形电子围栏全生命周期管理**：支持围栏的新建、启用、停用、软删除；支持围栏类型划分（禁区 FORBIDDEN、预警区 WARNING、临时作业区 OPERATION）；
  2. **地图交互式多边形顶点编辑**：前端地图画布支持拖拽控制点、增删顶点，实时计算闭合多边形面积与周长；
  3. **复杂几何拓扑防错校验**：采用 `Polygon2D` 射线交叉法与线段相交检测，对自相交多边形进行实时拦截与警告；
  4. **物理围栏外围逻辑缓冲区（本周新增）**：
     * 支持为物理硬隔离围栏配置外围逻辑缓冲带半径（`buffer_radius_m`，例如 `5.0m` 隔离带）；
     * 画布自动渲染内外双层边界：内圈为物理红色禁区，外圈为橙黄色逻辑缓冲区；
     * 实现前置分级预警：当人员触碰外围逻辑缓冲带时立即触发二级预警提示，从机制上杜绝“临近红线才报警”的滞后风险；
  5. **版本差分与边缘同步管控**：围栏编辑采用草稿与生效版本解耦机制，支持一键下发同步至边缘工控网关，并记录同步状态（SYNCED / PENDING / FAILED）。

### 2.4 设备防碰撞监测与安全联锁模块
* **模块路径**：`/devices`
* **核心功能清单**：
  1. **大型装卸设备全量台账**：覆盖轨道式龙门吊（CRANE）、集装箱翻箱机（TIPPER）、正面吊与水平运输平板车；
  2. **双机相对间距实时毫米波测距**：多对交叉设备相对运动矢量测算，实时计算相对速度、接近加速度及预测碰撞剩余时间（TTC）；
  3. **六级安全联锁卡控梯级**：
     * `NORMAL`（间距 > 25m）：安全通行，正常作业；
     * `ATTENTION`（15m ~ 25m）：蓝标提示，雷达波束聚焦；
     * `SLOW_DOWN`（10m ~ 15m）：黄色预警，触发减速建议；
     * `ALARM`（5m ~ 10m）：橙色声光报警，司机室蜂鸣；
     * `INTERLOCK_STOP`（< 5m）：红色紧急联动停机，下发 PLC 动力回路切断请求；
     * `MANUAL_TAKEOVER`：人工干预与现场调度强制接管；
  4. **防碰撞去重与告警中心联动**：设备 `activeAlertId` 彻底弱化为瞬态缓存，统一以 `safety_alert (dedup_key, status_code)` 为去重权威，防止告警风暴。

### 2.5 AI 视觉违规分析与事件复核模块
* **模块路径**：`/ai`
* **核心功能清单**：
  1. **CCTV 视频源与抓拍事件列表**：汇聚 01~04 号球机/枪机实时视频帧抓拍事件，分类展示违规行为；
  2. **PPE 劳动防护合规性分析**：智能识别未戴安全帽（NO-HELMET）、未穿反光背心（NO-VEST）、高空作业未系安全绳等隐患；
  3. **危险作业区周界入侵侦测**：基于画面脚底接地点与 ROI 多边形求交，秒级判定人员越界违规；
  4. **证据链核查与人工复核闭环**：展示抓拍高清大图、检测框标注、置信度数值，安全员可一键执行“确认违规派单”或“标记误报作废”，状态实时回写。

### 2.6 AI 模型管理与工况在线识别案例（本周新增）
* **模块路径**：`/ai/models`
* **核心功能清单**：
  1. **工业级 AI 模型库选用与热切换**：
     * 预置 5 款经过实地评测的工业算法模型：
       * **`YOLOv8-SafetyHelmet-v2.3`（默认激活选用）**：PPE 穿戴合规检测，mAP@0.5: 93.4%，ONNX Runtime 引擎，时延 14.2ms，FPS 70；
       * **`YOLOv11-DangerZone-v1.2`**：危险禁区与缓冲区入侵识别，mAP@0.5: 95.1%，TensorRT 引擎，时延 11.8ms，FPS 85；
       * **`RT-DETR-FlameSmoke-v3.0`**：明火与烟雾早期探测，mAP@0.5: 91.8%，TensorRT 引擎，时延 16.5ms，FPS 60；
       * **`FastPose-FallDetection-v2.0`**：人体姿态估计与人员跌倒识别，mAP@0.5: 89.6%，OpenVINO 引擎，时延 18.0ms，FPS 55；
       * **`CraneSway-Vision-v1.5`**：起重吊钩偏摆与吊装防撞，mAP@0.5: 92.3%，ONNX Runtime 引擎，时延 13.5ms，FPS 74；
     * 支持一键切换当前全局生效模型，触发 `/api/v1/ai/models/{id}/select` 并通过 WebSocket 广播 `ai.model_selected`；
  2. **在线超参数调优与边界卡控**：
     * 支持可视化修改置信度阈值（Confidence）与交并比阈值（IoU），后端设置 `0.20 ~ 0.99` 强校验；
  3. **多维模型性能健康监控**：卡片式呈现 mAP 精度进度条、计算帧率（FPS）、推理时延（ms）、推理引擎与检测类别标签；
  4. **实际工况在线识别案例工作台**：
     * 预置 5 组真实场景（01号主跨钢构立柱作业面 PPE 检测、吊装盲区人员检测、材料堆放区烟火检测等）；
     * 4K 工业摄像头 SVG 高清视口渲染，具备四角准星瞄准界面；
     * 前向推理运算：调用后绘制带有工业准星的彩色 Bounding Box 目标检测框（如红框 `NO-HELMET` 96.2%、橙框 `NO-VEST` 91.5%、绿框 `HELMET` 98.1%）；
     * 目标检测清单实时输出目标类别、置信度与坐标位置；
     * 支持置信度滑块实时过滤低置信度检测框；
     * **业务闭环建单**：点击“生成正式安全告警”自动向后端提交转单，挂载 `AlertEvidence.AiEvidence` 多模态证据，生成中高风险正式告警单。

### 2.7 统一安全告警处置主链模块
* **模块路径**：`/alarms`
* **核心功能清单**：
  1. **全域安全事件大一统收口**：汇聚人员越界、设备防撞、AI视觉穿戴、边缘离线全部异常，统一告警编号 `ALM-yyyyMMdd-NNN`；
  2. **正交生命周期状态机**：
     * 状态机规范收口为 8 态：`PENDING_CONFIRM`（待确认）→ `CONFIRMED`（已确认）→ `PENDING_ASSIGNMENT`（待派单）→ `PENDING_PROCESS`（待处置）→ `PROCESSING`（处置中）→ `PENDING_REVIEW`（待复核）→ `CLOSED`（已归档），以及作废态 `CANCELLED`；
     * 风险升级仅跃迁 `risk_level_code`（NORMAL → WARNING → SEVERE → URGENT），不篡改主生命周期状态；
  3. **决策来源血缘追溯（Decision Provenance）**：精准追溯告警决策源（FENCE / RULE / AI_MODEL / COLLISION / EDGE / MANUAL）及当时使用的版本号与规则编号；
  4. **责任人快照与标准 USR 账号映射**：责任人强关联 `assignee_user_code`，并保留处理人只读名称快照；
  5. **事件时间线保序流转**：记录报警、认领、派发、到场、整改、复核全流程时间线，按序号强制保序。

### 2.8 统计分析与安全决策模块
* **模块路径**：`/analytics`
* **核心功能清单**：
  1. **多周期安全态势趋势**：近 7 日 / 近 30 日告警数量波动态势折线图；
  2. **高频隐患类型分布**：越界、未佩戴安全帽、设备过近、人员滞留各占比环形图；
  3. **作业区域风险热度排行**：按各作业区域统计违规频度，识别重点风险区；
  4. **告警处置平均时效（MTTR）**：统计告警从发生到闭环归档的平均处置时长；
  5. **多维报表导出**：支持将安全卡控周报、月报数据导出为 CSV/Excel。

### 2.9 规则引擎配置与版本解耦模块
* **模块路径**：`/rules`
* **核心功能清单**：
  1. **卡控判定规则全量库**：管理越界判定、滞留时间超限、防碰撞安全间距、PPE 违规规则；
  2. **版本保护机制（B5-04 落地）**：在线编辑规则时保持主表 `active_version` 运行态不变，新内容写入版本子表草稿（DRAFT），发布时原子切换主版本指针；
  3. **区域适用性多对多绑定**：通过子表灵活关联一条规则适用的多个作业区域；
  4. **边缘网关同步状态追踪**：跟踪各边缘工控机对规则版本的下载与生效情况。

### 2.10 运维监控与边缘断网自治模块
* **模块路径**：`/operations`
* **核心功能清单**：
  1. **全栈服务健康拓扑**：监控云端 Spring Boot、openGauss 数据库、Edge-AI 推理机、WebSocket 服务节点连通状态；
  2. **边缘计算节点（EDGE-01~04）状态**：CPU 负载、内存占用、GPU 显存、网络延迟、在线心跳；
  3. **断网离线队列与幂等补传（B5-05 落地）**：

### 3.3 数据库防物理删除治理与有效数据查询视图

为了彻底满足工业安全生产事故倒查、司法级存证审计的要求，本系统在数据库层实施了严格的**防物理删除治理体系**：

#### 1. 库级防物理删除硬拦截触发器（Guard Triggers）
在 openGauss 数据库底层部署全局拦截函数 `safety.fn_prevent_physical_delete()`：
```sql
CREATE OR REPLACE FUNCTION safety.fn_prevent_physical_delete()
RETURNS TRIGGER AS $$
BEGIN
    RAISE EXCEPTION 'Physical DELETE is strictly prohibited on table % (Audit & Safety Compliance)', TG_TABLE_NAME;
    RETURN NULL;
END;
$$ LANGUAGE plpgsql;
```
该函数作为 `BEFORE DELETE` 触发器挂载到了**全库全部 25 张表**上。无论是应用程序代码还是 DBA 终端，任何物理 `DELETE` 执行均会被数据库引擎硬拦截并报错回滚。

#### 2. 外键级联禁用（ON DELETE RESTRICT）
全库 11 处子表外键（`safety_alert_timeline`, `evidence`, `treatment`, `linkage`, `rule_version`, `fence_version` 等）一律声明为 `ON DELETE RESTRICT`，彻底禁用 `ON DELETE CASCADE`，消除隐式级联清空隐患。

#### 3. 逻辑删除与部分唯一索引（Soft Delete & Partial Unique Indexes）
全部台账主表均包含 `is_deleted BOOLEAN NOT NULL DEFAULT FALSE` 字段，且业务编号唯一索引统一改造为部分唯一索引（Partial Index）：
```sql
CREATE UNIQUE INDEX uk_personnel_code_active ON safety.safety_personnel (personnel_code) WHERE is_deleted = false;
CREATE UNIQUE INDEX uk_fence_code_active ON safety.safety_fence (fence_code) WHERE is_deleted = false;
```
**业务优势**：在彻底保留历史软删除记录用于审计的同时，允许后续业务复用已被逻辑注销的编号。

#### 4. 统一有效数据查询视图（Unified Active Views）
为避免业务层和报表端漏写 `WHERE is_deleted = false`，数据库底层直接封装了 11 张统一视图：

| 视图名 | 底层物理表 | 预设数据过滤条件 | 业务场景与用途 |
| :--- | :--- | :--- | :--- |

### 4.2 本周核心攻坚成果与技术突破

本周（2026-10-05 ～ 2026-10-10）研发团队重点突破了以下 5 项关键业务与技术攻坚项：

1. **动态菜单导出与解耦架构**：
   * 将 SCS 系统的全部功能模块配置提取并沉淀为标准 CSV 文件（`docs/scs_module_menu.csv` 与桌面同步副本），解除了前端代码与硬编码菜单的耦合，支持系统后续通过配置动态挂载和多角色展示。
2. **全库防物理删除（Zero Physical DELETE）架构落地**：
   * 针对安全生产与审计规范，在数据库层杜绝物理删除行为。编写了通用库级触发器拦截函数 `safety.fn_prevent_physical_delete()` 并覆盖全部 25 张表，将外键级联全部收敛为 `ON DELETE RESTRICT`；
   * 针对台账软删除引起的唯一性约束冲突，在 openGauss DDL 中引入**部分唯一索引（Partial Index）**；
   * 封装 11 张 `safety.v_*` 统一查询视图，在底层对有效数据进行统一过滤，业务查询层免于手写过滤逻辑。
3. **人员定位高频刷新在线配置机制**：
   * 实现了人员定位刷新周期的在线可调能力（1s ~ 60s），支持调度员根据现场网络工况与电池功耗动态优化采样频率，并通过 WebSocket 实时同步至所有在线前端。
4. **电子围栏编辑与物理外围逻辑缓冲区（前置隔离带）**：
   * 研发了电子围栏外围逻辑缓冲区算法，支持在物理围栏外围设立参数化预警带（`buffer_radius_m`）；
   * 前端地图实现了内外双层边界的动态绘制与视觉层级渲染，解决了“人员临近红线才报警”的滞后难题，实现前置降速与预警。
5. **AI 工业模型库选用、管理菜单与端到端实测案例**：
   * **多模型选用**：预置 5 款经过实测的工业级检测模型（涵盖安全帽/反光衣、禁区入侵、烟火、跌倒、吊钩），支持一键激活热切换与参数调优；
   * **导航结构扩展**：在侧边栏作业安全分组下新增 `/ai/models`（AI 模型管理），并抽象 `AiSubNav.vue` 二级子导航组件，打通复核与模型管理；
   * **实测案例工作台**：构建了基于 4K 工业摄像头视口的在线推理组件，支持 Bounding Box 准星标定框实时绘制、置信度动态过滤，并一键联动 `AlertService` 构造多模态 `AiEvidence` 正式建单，形成完整业务闭环。
